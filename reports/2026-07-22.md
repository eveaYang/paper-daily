## 必读论文

### 1. 基于图结构的 MARL 有源电压控制，真正把“电网拓扑”变成了策略学习的一部分

- 中文标题：基于图神经网络的多智能体强化学习有源电压控制：性能与拓扑鲁棒性
- 英文原题：Graph neural network-based multi-agent reinforcement learning for active voltage control: Performance and topology robustness
- 作者：Chijioke Eze, Chetan Prakash, Antonello Monti
- 作者机构：RWTH Aachen University（公开可核验部分）
- 来源：`Energy and AI`
- 发表时间：2026-07-06
- DOI / 官方链接：[10.1016/j.egyai.2026.100835](https://doi.org/10.1016/j.egyai.2026.100835)
- 数据链接：[公开数据 1](https://bit.ly/3KK83kU)、[公开数据 2](https://bit.ly/44TV4Uz)
- 代码 / 项目页：未检到稳定公开代码或项目页
- 相关程度：高
- 关联方向：配电网电压控制、图神经网络、多智能体强化学习、拓扑鲁棒性
- 是否仅基于摘要判断：是

**为什么值得读**

这篇的关键价值不在“又一个 RL 配电网控制器”，而在于它把配电网的拓扑关系显式编码进 agent 的策略网络。对你来说，这比单纯比较 PPO、SAC 或 MADDPG 更有研究含金量，因为它直接回答了“电网拓扑变化时，策略还能不能稳住”这个工程问题。

**主题分析**

论文解决的是分布式光伏渗透提升后，有源电压控制在中大型配电系统中的可扩展性与拓扑适应性问题。传统集中式 OPF 或常规 RL 往往在网络规模扩大、支路结构变化、环网场景出现时性能显著下滑。该文更偏“控制与拓扑泛化”而非单纯预测。

**方法介绍**

核心框架是在多智能体强化学习中引入图神经网络 actor。公开摘要可稳定确认的设计包括：

1. 以图卷积或图注意力模块处理配电网连接关系，使 agent 不再只依赖本地时序状态。
2. 在相同 MARL 框架下对比多种 graph actor 变体，评估不同图消息传递方式的收益。
3. 输出分布式电压控制策略，用于协调不同节点或控制设备的响应。

从研究思路看，这篇论文的真正重点是“让控制器看懂网络结构”，而不是继续靠 reward engineering 强行补偿拓扑信息缺失。

**实验、数据与结果**

公开摘要给出的实验信息比较扎实：

1. 在 IEEE 33、141、322 母线系统上验证。
2. 在 141 母线系统中，图结构 MARL 将电压越限减少约 `47%`。
3. 在 322 母线系统中，最优模型把失控率降到 `3.20%`。
4. 在环网测试中，相比 MLP actor 基线，图结构 actor 进一步降低网络损耗并提升鲁棒性。

这说明它的优势不只体现在小样例，而是开始触到更复杂配电网控制的可扩展边界。

**局限性与风险**

主要风险仍是仿真主导。摘要没有展示真实配网在线部署、通信延迟、测量噪声、设备老化或保护约束细节。另一个风险是图结构虽然提高了泛化，但对状态可观测性、控制设备布点和训练分布依然敏感。

**对你可继续延伸的方向**

1. 迁移到含储能、EV 充电站和柔性负荷的主动配电网控制。
2. 在 graph actor 外再叠加安全层，把潮流、线流和设备动作速率约束显式投影。
3. 与多时间尺度控制结合，让日前优化给出参考点，MARL 负责实时微调。
4. 引入市场或需求响应代理，扩展成配电侧 VPP 多主体协同控制。

### 2. 电价预测如果不建模报价行为，很容易只是在价格序列上“拟合结果”而不是“理解市场”

- 中文标题：基于报价策略行为分类的可解释电价预测
- 英文原题：Interpretable electricity price forecasting based on behavioral classification of bidding strategies
- 作者：Yunxiao Bai, Siyu Lv, Wen Zhang, Qian Sun, Yidan Zheng, Yunjie Rao
- 作者机构：官方公开摘要页未稳定展开完整机构信息
- 来源：`Electric Power Systems Research`
- 发表时间：2026（公开摘要页未显示更细日期）
- DOI / 官方链接：[10.1016/j.epsr.2026.113176](https://doi.org/10.1016/j.epsr.2026.113176)
- 代码 / 数据 / 项目页：未检到稳定公开链接
- 相关程度：高
- 关联方向：电价预测、电力市场、竞价行为、可解释机器学习
- 是否仅基于摘要判断：是

**为什么值得读**

你如果还在考虑“怎样让电价预测更贴近市场机制”，这篇比单纯换 Transformer backbone 更值得优先看。它把机组报价策略先做行为分类，再把行为特征送入预测器，本质上是在重建价格形成过程里的中观层信息。

**主题分析**

论文针对的核心问题是：传统电价预测多关注负荷、气象、历史价格与发电出力，却弱化了报价策略本身。这样虽然可能拿到不错误差，但对异常价格、策略切换与市场博弈的建模能力往往不足。它属于“机制感知电价预测”而不是纯统计拟合。

**方法介绍**

公开摘要中可确认的主要模块包括：

1. 先用人工智能分类方法把报价行为分为激进、稳定、保守三类。
2. 基于分类结果构造 `CSBF`（competitive strategy behavior features）特征。
3. 用 `VMD` 分解价格序列，再结合 `Bagging-XGBoost` 进行预测。
4. 用 `SHAP` 做后验解释，识别不同特征组对价格的影响。

这套思路的实用价值在于：它给出了一个可落地的机制特征工程模板，你以后做节点电价、区域价差或虚拟电厂报价问题都能直接借鉴。

**实验、数据与结果**

摘要公开的实验设定很有参考价值：

1. 使用中国南方某省 `2024` 年全年的实际市场数据。
2. 数据分辨率为 `15` 分钟。
3. 输入特征覆盖负荷、气象、发电功率、报价与机组参数。
4. 结果显示 `CSBF` 特征显著提升预测精度，并在 `RMSE` 与 `R²` 上优于对比模型。

公开页面没有披露完整误差表和每个基线的具体数值，因此今天适合把它当“方法路线重点关注”，而不是把数值增益当成已完全核验的定论。

**局限性与风险**

最大风险是数据门槛。很多市场拿不到高频、结构化的真实报价单。另一个风险是行为分类本身受市场规则和主体类型影响，跨市场迁移时可能需要重定义策略类别。若做海外市场或节点价场景，CSBF 未必能直接套用。

**对你可继续延伸的方向**

1. 把报价行为分类扩展成图结构或时序状态机，用于节点电价预测。
2. 与概率预测结合，让行为特征驱动分位数或场景电价预测。
3. 将行为分类嵌入强化学习报价 agent，研究预测与决策的闭环协同。
4. 引入拥塞、潮流和输电瓶颈特征，把“市场行为”与“网络物理”统一到同一个预测框架中。

### 3. 负荷预测不一定只看历史序列；把“未来已知计划”作为上下文输入，往往比继续加深模型更有效

- 中文标题：在负荷预测中引入“预期未来”：基于上下文增强 Transformer 的方法
- 英文原题：Integrating the expected future in load forecasts with contextually enhanced transformer models
- 作者：Raffael Theiler, Leandro Von Krannichfeldt, Giovanni Sansavini, Michael F. Howland, Olga Fink
- 作者机构：官方公开摘要页未稳定展开完整机构信息
- 来源：`Energy Reports`
- 发表时间：2026-06
- DOI / 官方链接：[10.1016/j.egyr.2026.109223](https://doi.org/10.1016/j.egyr.2026.109223)
- 数据链接：[Zenodo](https://zenodo.org/records/18986667)
- 代码 / 项目页：未检到稳定公开代码或项目页
- 相关程度：高
- 关联方向：负荷预测、Transformer、上下文建模、异常误差抑制
- 是否仅基于摘要判断：是

**为什么值得读**

这篇论文的思路对电力负荷、新能源功率预测甚至 EV 充电负荷都很有启发。它提醒你：很多任务里“未来并不完全未知”，排班、时刻表、节假日、占用率计划、检修计划这些信息如果能提前拿到，应该作为正式输入，而不是只靠历史序列猜。

**主题分析**

论文解决的是“历史数据足够多，但仍然抓不住未来事件驱动变化”的问题。它关注的是预测系统如何吸收上下文知识，而不是只在模型结构上微调。因此更接近“问题设定升级”而非单纯模型创新。

**方法介绍**

公开摘要显示其框架是一个上下文增强的 seq2seq Transformer，大致包含三层思路：

1. 用历史负荷序列编码已观测状态。
2. 把未来时刻表、规划占用率等上下文信息编码成辅助输入。
3. 在解码阶段联合利用历史依赖与未来上下文，输出多步负荷预测。

这类设计的普适性很强。你可以把“未来时刻表”替换成充电预约、天气预报、市场公告或工业产线排班，迁移到别的能源任务里。

**实验、数据与结果**

摘要公开了比较清晰的量化结果：

1. 在全国铁路能耗预测中，`MAE` 降低约 `26.6%`。
2. 在楼宇能耗预测中，`MAE` 降低约 `56.3%`。
3. 大误差事件分别减少约 `87.8%` 和 `93.0%`。

这些结果说明，上下文信息的收益不仅体现在平均误差，更体现在极端偏差控制上，这对调度与备用安排非常重要。

**局限性与风险**

它对“可提前获得的高质量未来信息”有依赖。如果计划本身经常变更、占用率预测不准、或上下文存在严重缺失，增益可能明显缩水。另一个风险是不同任务的上下文形式差别很大，迁移时需要重新设计输入对齐方式。

**对你可继续延伸的方向**

1. 迁移到 EV 充电负荷预测，把预约、停车时长、交通流计划作为未来上下文。
2. 迁移到节点负荷和台区负荷预测，把检修、转供、活动日历和分布式资源计划纳入输入。
3. 与图神经网络结合，让上下文信息在电网拓扑上扩散，而不是只做全局拼接。
4. 用于价格预测时，可把负荷、风光概率场景、市场公告与燃料计划作为“预期未来”信息。

## 值得跟进

### 4. EV、充电站和电网协同，不该只学一个站端控制器；这篇直接把“车-站-网”拆成多主体联合优化

- 中文标题：基于多智能体强化学习的电动汽车、充电站与电网协同交互
- 英文原题：Coordinated interaction of electric vehicles, charging stations, and the power grid using multi-agent reinforcement learning
- 作者：Yuchen Li, Hengyuan Zhao, Zhixuan Song, Xuequn Chong, Ruixuan Chen, Lanyu Li, Xiaonan Wang
- 作者机构：官方公开摘要页未稳定展开完整机构信息
- 来源：`Advances in Applied Energy`
- 发表时间：2026-06
- DOI / 官方链接：[10.1016/j.adapen.2026.100274](https://doi.org/10.1016/j.adapen.2026.100274)
- 代码 / 数据 / 项目页：公开摘要页未给出稳定链接
- 相关程度：高
- 关联方向：EV 充电调度、多智能体强化学习、动态定价、交通能源耦合
- 是否仅基于摘要判断：是

**为什么值得读**

这篇的价值在于问题拆分很对。很多 EV 论文只学站端功率控制，忽略 EV 用户响应与电网侧反馈。这篇把车、站和网都纳入多主体决策，对你后续做交通能源耦合、VPP 或聚合商控制非常有参考意义。

**主题分析**

论文关注的是双向充放电和动态定价下，如何同时兼顾充电站利润、用户成本和电网可再生消纳。它本质上是一个带经济激励的协同调度问题，而不仅是充电曲线平滑化。

**方法介绍**

摘要公开的核心设计包括：

1. 采用 `Transformer-enhanced multi-agent actor-critic` 框架。
2. 采用集中训练、分散执行思路协调不同主体。
3. 充电站 agent 负责动态定价，EV agent 负责双向充放电行为。
4. reward 中显式计入可再生利用、用户成本、站端收益与电池老化成本。

这类 reward 设计对实际落地更有意义，因为它避免了只用“削峰填谷”这种过于抽象的单目标。

**实验、数据与结果**

摘要公开的代表性结果比较完整：

1. 充电站利润提升约 `33.5%`。
2. 用户充电成本下降约 `4.3%`。
3. 可再生能源分配量提升约 `40.7%`。

这说明它不是靠牺牲某一方来换另一方收益，而是试图做更平衡的系统级协调。

**局限性与风险**

目前仍以仿真验证为主。真实场景下，用户响应模型、价格接受度、车主离站不确定性、配电网约束和通信延迟都会带来额外难度。若没有真实站端数据，reward 设计和行为建模很容易过拟合假设。

**对你可继续延伸的方向**

1. 直接迁移到站群聚合商或园区级虚拟电厂控制。
2. 把离站时间预测、价格预测和充电控制做成 decision-focused 闭环。
3. 引入配电网潮流约束和节点电价，做真正的“车-站-网-市”四层协同。
4. 与交通仿真或出行链数据结合，增强行为真实性。

### 5. 极端天气下的综合能源负荷建模，不一定非要更深神经网络；物理信息稀疏回归反而更适合做可解释系统模型

**为什么值得读**

### 6. 代表性论文：LLM 不直接替代控制器，而是负责把规划、政策和新闻转成配电控制可用的上下文知识

- 中文标题：将上下文知识融入配电网 Volt/Var 控制：大语言模型驱动的模糊推理与模型预测控制方法
- 英文原题：Integrating contextual knowledge into volt/Var control of distribution networks: a large language model-driven fuzzy inference and model predictive control approach
- 作者：Jiafeng Lin, Jing Qiu, Sihai An, Zongyu Yao, Weiyi Tian, Xin Lu
- 作者机构：官方公开摘要页未稳定展开完整机构信息
- 来源：`Applied Energy`
- 发表时间：2026-04-15
- DOI / 官方链接：[10.1016/j.apenergy.2026.127481](https://doi.org/10.1016/j.apenergy.2026.127481)
- 代码 / 数据 / 项目页：未检到稳定公开链接
- 相关程度：中高
- 关联方向：Volt/Var 控制、LLM、模糊推理、模型预测控制
- 是否仅基于摘要判断：是
- 代表性原因：属于近两年内较早把 LLM 放进配电控制链、且角色定位相对务实的一篇正式论文

**为什么值得读**

现在很多“LLM+电网”工作容易停在概念演示层，这篇的优点是把 LLM 放在它更擅长的位置：抽取非结构化上下文、生成模糊规则、辅助设备选址和控制决策，而不是直接取代底层控制器。

**主题分析**

论文要解决的是传统 Volt/Var 控制只看实时量测，却没有有效吸收规划文本、政策要求、新闻事件等外部知识的问题。实际工程里，这些上下文会影响设备布点、控制偏好和运行边界，但很难直接进数值模型。

**方法介绍**

摘要公开的核心流程可以概括为：

1. 用 LLM 从新闻、政策和规划报告中抽取上下文知识。
2. 将抽取结果转成模糊规则与设备适配评分。
3. 用模糊推理系统为不同位置的控制设备生成适宜性判断。
4. 通过 `MPC` 协调集中式慢控制与分布式快控制。

这条路线的价值在于给了你一个更可信的 LLM 落点：让 LLM 服务于知识工程与上层决策，而不是直接输出底层动作。

**实验、数据与结果**

公开摘要表明，该方法在案例研究中提升了电压稳定性，并减少了开关动作和网络损耗。但公开页面没有稳定给出完整量化表格，因此今天更适合把它当“方法范式参考”，而不是把数值性能作为重点。

**局限性与风险**

风险主要来自两端：一端是 LLM 抽取结果对 prompt、语料质量和知识边界敏感；另一端是模糊规则与 MPC 的接口设计需要较强人工先验。若上下文抽取失真，可能把噪声引进控制链。

**对你可继续延伸的方向**

1. 把 LLM 用作约束提取器、场景解释器或策略审查器，而不是直接控制器。
2. 与图神经网络、RL 或 OPF 联合，形成“LLM 负责知识注入，数值模型负责优化控制”的混合框架。
3. 迁移到需求响应、虚拟电厂、恢复调度和市场机制解释任务。
4. 用 RAG 和企业内部知识库约束 LLM 输出，降低幻觉风险。
